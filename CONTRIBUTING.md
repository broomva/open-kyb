# Contributing to open-kyb

Thank you for contributing to `open-kyb`!

## Development Setup

1. Install Python `>=3.15`, [`uv`](https://docs.astral.sh/uv/), and `poppler` (`pdftotext`, `pdftoppm`, `pdfinfo`).
2. Sync dependencies:
   ```bash
   uv sync
   ```
3. Regenerate synthetic example packets (if modifying `scripts/make_examples.py`):
   ```bash
   uv run python scripts/make_examples.py
   ```

## Quality Gates

Before opening a pull request, ensure all offline gates pass locally:

```bash
make lint
uv run pytest -q
uv run kyb verify
make demo
```

## Coding Standards

- **Strict separation of duties:** Models extract and escalate; deterministic code evaluates policy rules and sets decision status. Never allow a model call to clear a triggered rule.
- **No secrets or hardcoded project IDs:** All GCP Vertex AI configuration must come from `KYB_VERTEX_PROJECT`, `KYB_VERTEX_QUOTA_PROJECT`, and `KYB_VERTEX_LOCATION` (default `global`) using Application Default Credentials.
- **Formatting and linting:** We enforce `ruff check` and `ruff format` with a 100-character line limit (`make fmt` / `make lint`).
- **Synthetic data only:** Never commit real company filings, personally identifiable information (PII), or client material. Use synthetic packets generated by `scripts/make_examples.py`.
