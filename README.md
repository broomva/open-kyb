# open-kyb

`open-kyb` is an autonomous Know Your Business (KYB) compliance review system built around a strict separation of duties: **models read and escalate, deterministic code decides, and a compliance officer signs.**

Every extracted claim is checked by a blind cross-family pixel witness before entering the typed fact graph, every compliance rule (`SCR-`, `JUR-`, `OWN-`, `GOV-`, `PEP-`, `DOC-`, `OPS-`, `ACT-`, `MOD-`, and the score thresholds) is parsed directly from `compliance_rules.md` at decision time and evaluated by deterministic code, and every action is recorded in a hash-chained audit ledger (`ledger/audit.jsonl`).

## Architecture

```text
Applicant Packet (PDFs: text-layer + scanned/handwritten filings)
   │
   ├──► 1. Intake & Page Rendering (`kyb ingest`, `kyb pages`)
   │       Content-addressed bronze manifest + 300-dpi PNGs + pdftotext layers
   │
   ├──► 2. Blind Layout & Isolated Document Readers (`kyb layout`, `kyb-reader`)
   │       One hook-attested reader subagent per document (cannot see other docs,
   │       watchlists, or policy thresholds); emits bounding-box-cited claims
   │
   ├──► 3. Cross-Family Pixel Witness (`kyb verify-quotes` / Vertex Gemini)
   │       Sees only cropped pixel regions (never reader claims or text layer);
   │       detects strike-throughs, handwritten amendments, and prompt injections
   │
   ├──► 4. Deterministic Fact Derivation & Watchlist Screening (`kyb run`)
   │       Entity resolution, UBO ownership graph unwrapping, cross-document
   │       conflict detection, and Jaro-Winkler + transliteration screening
   │
   ├──► 5. Policy Parser & Rule Engine (`kyb decide`)
   │       Parses `compliance_rules.md` (guarded by section skeleton hashes);
   │       evaluates policy rules + score bands; runs veto-only safety judges;
   │       emits schema-validated `KYBDecision` with verbatim citations
   │
   └──► 6. Copilot Q&A & Officer Signing Gate (`kyb ask`, `kyb sign`, `kyb audit verify`)
           Code-rendered Q&A answers over verified facts/snippets; enrolled officer
           cryptographic signing gate; tamper-evident SHA-256 hash chain
```

## Safety Model

1. **Models escalate and never clear.** Language and vision models extract candidate claims from documents and answer narrow, bounded semantic predicates. No model output can waive a triggered rule, lower a risk score, or approve an applicant.
2. **Per-document reader isolation.** Each document in an applicant packet is read by an isolated subagent (`kyb-reader`) enforced by runtime hooks (`PreToolUse`, `SubagentStart`, `SubagentStop`). A reader can only read its assigned document pages and crops, preventing cross-document hallucination or rationalisation of conflicting ownership stakes.
3. **Blind cross-family pixel witness.** Every claim bbox is cropped at 300 dpi and transcribed by a model from a distinct model family over GCP Vertex AI (`vertex-gcp`) with zero access to the reader's claim or the PDF text layer. Only claims corroborated by the pixel witness reach `W2` assurance.
4. **Deterministic code decides.** `kyb.policy` parses parameters and thresholds directly from `compliance_rules.md` (verifying section skeleton hashes so unrepresentable prose edits trigger a visible `POLICY-GUARD` manual review) and composes rule outcomes under strict precedence: `REJECT > REVIEW > score thresholds`.
5. **Veto-only judges.** Independent deterministic and cross-family judges (`J-ARITH`, `J-PRECEDENCE`, `J-VERIFICATION`, `J-READER-ISOLATION`, `J-APPROVAL-ASSURANCE`, `J-SUPPORT`) can downgrade `APPROVED` or `REJECTED` to `MANUAL_REVIEW`, never the reverse.
6. **An officer signs.** Decisions emitted by `kyb decide` enter `pending_signature`. Only an enrolled compliance officer with a verified token can sign an approval, rejection, or documented override into the hash-chained ledger.

## Quickstart

### Prerequisites

- Python `>=3.15` and [`uv`](https://docs.astral.sh/uv/)
- `poppler` (`pdftotext`, `pdftoppm`, `pdfinfo`) on `PATH`
- For live Vertex AI witness calls: `gcloud` with Application Default Credentials (`gcloud auth application-default login`) and environment variables:
  - `KYB_VERTEX_PROJECT` (required for live Vertex calls)
  - `KYB_VERTEX_QUOTA_PROJECT` (optional, defaults to `KYB_VERTEX_PROJECT`)
  - `KYB_VERTEX_LOCATION` (optional, defaults to `global`)
  - Direct Gemini API keys (`GEMINI_API_KEY` / `GOOGLE_API_KEY`) are refused by design.

### Install & Test

```bash
uv sync
make lint
make test
```

### Run the Offline Verification Scorecard

```bash
uv run kyb verify
```

### Run the Offline Demo on `examples/`

`examples/` ships with an original machine-readable compliance policy (`examples/policy/compliance_rules.md`), synthetic watchlists (`examples/policy/watchlists.json`), and four synthetic applicant packets generated by `scripts/make_examples.py` (expected outcomes live in `examples/packets/expected_labels.json`, which `make demo` checks every decision against):

- `examples/packets/cl-andes-agro` — clean case (`APPROVED`, score `0`)
- `examples/packets/es-iberia-software` — registry-extract vs. utility-bill address mismatch and an expired proof of address, with scanned board minutes carrying a struck-through value and a handwritten amendment (`DOC-01`, `DOC-02`; `MANUAL_REVIEW`, score `35`)
- `examples/packets/sg-strait-capital` — Samoa trust holding layer over a Singaporean UBO who is a PEP within the lookback window, plus a maritime activity (`ACT-02`, `DOC-01`, `JUR-02`, `MOD-01`, `OWN-01`, `PEP-01`, `SCR-02`; `MANUAL_REVIEW`, score `90`)
- `examples/packets/ke-savanna-mineral` — precious-metals trader with a two-layer corporate holding chain and an invisible text-layer prompt injection in `02_ubo_declaration.pdf` (`ACT-02`, `GOV-03`; `MANUAL_REVIEW`, score `25`)

Regenerate the synthetic example PDFs and run the end-to-end offline demo:

```bash
uv run python scripts/make_examples.py
make demo
```

Or step through the CLI manually on an example packet:

```bash
uv run kyb init workspaces/kyb-demo --tenant kyb-demo --policy examples/policy/compliance_rules.md
uv run kyb -w workspaces/kyb-demo ingest examples/packets/cl-andes-agro --as-of 2026-10-25
uv run kyb -w workspaces/kyb-demo pages cl-andes-agro
uv run kyb -w workspaces/kyb-demo audit verify
```

### Install as a Claude Code Plugin

From a local checkout of this repository:

```bash
claude --plugin-dir ./plugin
```

Then ask the agent to review a synthetic packet using the `kyb-review` skill:

```text
Run a KYB review on the packet at examples/packets/es-iberia-software, with as_of 2026-10-25. Use the kyb-review skill.
```
